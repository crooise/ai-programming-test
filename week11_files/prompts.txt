  ② 무엇을 돌려주나   : 유효한 (이름, 점수) 목록을 반환
  ③ 실패하면 어떻게 하나 : 지정 경로에 파일이 없거나 폴더일 때 오류로 비정상 종료되지 않고 예외를 처리해 안내한다.
  ④ 쓰면 안 되는 것   :  외부 라이브러리 없이 파이썬 기본 기능만 사용
  ⑤ 예외 상황         : 파일이 비어 있거나 헤더만 있는 경우, 쉼표가 포함된 이름("최, 네번")이나 열 개수가 2개가 아닌 줄을 구분해 처리한다.
                       점수가 숫자로 변환되지 않거나 0 미만 100 초과(예: 105)인 경우 유효 데이터에서 제외한다.
                       점수 칸이 비어 있거나 공백만 있는 경우 정상 점수로 처리하지 않고 걸러낸다.
                       동일한 이름이 중복 등장할 때 이를 감지하여 건너뛰거나 중복 사실을 기록한다.
                       조건을 어겨 건너뛴 줄을 조용히 무시하지 않고, 몇 번째 줄이 어떤 이유로 제외되었는지 출력 또는 반환으로 보고한다.  
  ⑥ 조건 · 제약       : 첫 줄 헤더(name, score)는 데이터에서 제외하고, 외부 라이브러리 없이 파이썬 기본 기능만 사용하며, 오류 시 조용히 넘어가지 않고 처리해야 함
